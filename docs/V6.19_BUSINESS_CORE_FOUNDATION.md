# V6.19 — Business Core Foundation

## ARCHITECTURE CHANGE
Domain validation/entities plus verified storage repository introduced behind the current UI.

## BUSINESS RULES
Lifecycle contract explicit; one money engine.

## DATA MODEL
Canonical Customer/Product/QuotationItem helpers added without destructive migration.

## OLD LOGIC REMOVED
Duplicate preview/Excel total formulas and inline validation body.

## MIGRATION IMPACT
Existing keys and backup schema v4 remain compatible.

## TEST COVERAGE
New domain and storage repository unit gates; existing DOM/migration/smoke/build/Chromium gates remain mandatory.

## PHASE 5–7 ADDENDUM
- Stable itemId is assigned/persisted for quotation lines; catalog additions keep sourceProductId.
- Saved quotations carry recordId/quotationId/revision and preserve prior revision snapshots.
- The editor now rejects transitions outside the domain status machine.
- History revision behavior has a dedicated unit gate.

## NEXT DEPENDENCY
Move product/history commands out of main.js, add explicit schema migration engine/fixtures, then consolidate backup/import transaction services.

## PHASE 8–15 ADDENDUM
- Import pipeline remains parser -> mapper -> normalizer -> review -> transactional apply; existing V5.4/V5.5 regression gates are retained.
- Backup creation/validation/normalization moved to a dedicated service.
- Storage V1 schema marker + ordered migration engine added with fixture tests.
- Product bulk mutation now translates selection to stable itemId and executes through application commands.
- Canonical report view model added; preview totals and Excel totals consume it.
- Search normalization delegates to the domain helper; customer/product IDs use the shared ID generator.
- Service Worker precaches the full core module graph for stronger Standalone/offline startup.
- Integrity/quarantine primitives are available for non-destructive isolation of invalid collections.
- Full failure/DOM/migration/smoke/build/browser gates remain release blockers.

## RELEASE GATE
Do not merge while any CI or browser regression is red.

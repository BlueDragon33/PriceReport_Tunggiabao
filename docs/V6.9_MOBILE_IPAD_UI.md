# V6.9 — Mobile & iPad UI

## Mục tiêu

Đưa giao diện điện thoại và iPad lên cùng thế hệ UI/UX với desktop V6.8, loại bỏ các fallback V5 cũ đang ẩn header, Content Library và Flow Navigator.

## Kiến trúc responsive

V6.9 dùng một lớp CSS cuối cùng duy nhất: `src/responsive-v69.css`.

Lớp này chỉ sở hữu hành vi touch theo `data-device-class="tablet"` và `data-device-class="phone"`, không sửa bố cục in/PDF và không thay state nghiệp vụ.

### iPad / tablet

- Header 64 px luôn hiển thị.
- Bottom navigation 70 px với 5 thao tác chính.
- Studio chia đôi: Content Library 300 px + live A4 preview.
- A4 tự fit lại khi vào Studio hoặc xoay màn hình.
- Inspector Thiết kế là drawer bên phải.
- Content/Product Workspace gần fullscreen; Flow Navigator 7 bước nằm thành strip ngang phía trên.
- More menu là bottom sheet 4 cột.
- Template Library fullscreen, gallery 3 cột.
- Final Review fullscreen và giữ 4 KPI trên tablet.

### Điện thoại

- Header 58 px + bottom navigation 66 px.
- Studio chỉnh sửa một cột, ưu tiên Content Library; không ép A4 vào cạnh form.
- Xem A4 là màn hình riêng và tự fit theo viewport.
- Content/Product Workspace là app-screen `100dvh`.
- Flow Navigator là strip ngang.
- Form dùng font tối thiểu 16 px để tránh iOS zoom khi focus.
- Product editor chuyển sang card-first, ẩn spreadsheet header desktop.
- More menu là bottom sheet 2 cột.
- Inspector Thiết kế là drawer toàn chiều ngang.
- Template Library và Final Review fullscreen.

## Điều hướng

Bottom navigation sử dụng DOM hiện có và hiển thị:
1. Trang chủ
2. Soạn báo giá
3. Quản lý báo giá
4. Khách hàng & sản phẩm
5. Thêm

Trong menu Thêm, các mục Khách hàng, Sản phẩm, Thanh toán và Điều khoản đi qua `openContentBlock()`, vì vậy sử dụng đúng popup workflow V6.8 thay vì quay lại form inline cũ.

## Command palette

Trên touch, command palette dùng trạng thái `.command-palette-open` và hiển thị như overlay phía dưới header. Đóng bằng Esc hoặc chọn lệnh sẽ dọn trạng thái này.

## Regression gates

- DOM kiểm tra More menu mở đúng Customer/Product popup.
- DOM kiểm tra command palette overlay state được bật/tắt.
- Chromium desktop gate được giữ nguyên.
- Chromium iPad 834×1112 kiểm tra header, bottom nav, split Studio, A4 auto-fit, Flow Navigator, Product Workspace và More bottom sheet.
- Chromium iPhone 390×844 kiểm tra single-column Studio, fullscreen editor, 16 px input, card-first product entry, popup routing và report-view A4 fit.
- Smoke kiểm tra responsive stylesheet, device selectors, popup routing và PWA cache.

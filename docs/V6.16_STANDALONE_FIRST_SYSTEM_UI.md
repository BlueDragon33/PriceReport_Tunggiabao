# V6.16 — Standalone-first System UI

## Mục tiêu

V6.15 đã làm contract đúng với chính sách Standalone-first, nhưng tab **Thiết bị & hệ thống** vẫn dành quá nhiều không gian cho Application Management, Remote Admin và Control Plane. V6.16 sửa hierarchy UI để người dùng nhìn thấy trạng thái local-first trước và chỉ mở phần quản trị tập trung khi thực sự cần.

## Thiết kế mới

### Trạng thái chính

Ba card đầu trang chỉ gồm:

1. Thiết bị hiện tại.
2. Chế độ truy cập.
3. Dữ liệu nghiệp vụ local-first.

### Nội dung chính

- Thiết bị hiện tại: loại thiết bị, UI profile, mã cục bộ, viewport, platform, thời điểm nhận diện.
- Ranh giới dữ liệu: khẳng định quotation/customer data không đi vào Control Plane.

### Quản trị tập trung

Một `details` mặc định đóng chứa:

- Application Management;
- Remote Admin;
- mã registry KT-;
- Device Registry / Gateway / Admin API / Audit API readiness;
- policy Managed Mode.

Ở Standalone Mode, phần này không ảnh hưởng tới khả năng mở app hay tạo báo giá.

## Compatibility

- Giữ các ID runtime hiện hữu để test và Managed Mode không bị gãy.
- `classification-only` vẫn được hiểu như legacy input nhưng hiển thị thành local-first.
- Registry code vẫn được cập nhật khi Device Gate thật sự chạy.

## Responsive

- Desktop: quản trị tập trung mở thành 2 cột.
- Tablet: panel kỹ thuật chuyển về 1 cột.
- Phone: card quản trị và panel kỹ thuật đều 1 cột; summary xếp dọc.

## Không thay đổi

- Không đổi dữ liệu báo giá, khách hàng, sản phẩm.
- Không đổi backup schema.
- Không đổi import/export hoặc A4/PDF.
- Không bật Managed Mode mặc định.

# UI/UX Constitution Changelog

This changelog records **design-governance policy changes**, not ordinary CSS edits.

## 1.0 — Initial Constitution

- Established permanent UI/UX governance for PriceReport_Tunggiabao.
- Defined product North Star and design priority order.
- Standardized visual language, design tokens, typography, spacing, radius and elevation.
- Defined Application Shell, navigation, Dashboard and Quotation Studio policies.
- Defined data-entry workspace, modal, Product and Customer UX policies.
- Defined forms, buttons, icons, table, card, status, toast, empty-state and error contracts.
- Defined responsive, breakpoint, viewport, accessibility and keyboard governance.
- Defined A4 Preview, Report Document and Print/PDF boundaries.
- Preserved Standalone/local-first behavior and optional Application Management.
- Defined CSS ownership, component governance, deprecated UI policy and UI debt policy.
- Established Source-of-Truth, exception, versioning, Future Agent Protocol and compliance checklist.
- Established incremental migration rather than big-bang rewrite.

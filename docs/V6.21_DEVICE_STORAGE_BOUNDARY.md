# V6.21 Device Storage Boundary

V6.21 completes the repository boundary for the remaining runtime device-profile persistence.

## Change

- `src/device-profile.js` no longer calls `localStorage.getItem/setItem/removeItem` directly.
- Device metadata uses the same Storage Repository abstraction as the core application.
- The module still remains optional runtime/management metadata and does not become a core business dependency.

## Safety

- Device-profile storage failures remain non-blocking for Standalone mode.
- No quotation, customer, product, history, backup or template schema changes.
- Existing key `tunggiabao-device-profile-v1` remains unchanged.
- Smoke regression prevents direct localStorage methods from returning to device-profile.js.

# V6.17 — System UX Readability

## Mục tiêu

V6.16 đã đưa quản trị tập trung xuống lớp tùy chọn, nhưng nội dung bên trong vẫn có nhiều thuật ngữ kỹ thuật và cỡ chữ nhỏ. V6.17 làm phần này dễ hiểu và dễ đọc hơn mà không thay đổi contract hay business data.

## Thay đổi

### 1. Ngôn ngữ người dùng
- Control Plane → Dịch vụ quản trị thiết bị.
- Device registry → Danh sách thiết bị.
- Device gateway → Cổng kiểm duyệt thiết bị.
- Admin API → Kết nối quản trị.
- Remote audit API → Nhật ký quản trị.
- Remote Admin → Quản trị từ xa.
- Các nhãn ranh giới dữ liệu được diễn đạt theo hành vi thực tế.

### 2. Readability
- Tăng cỡ chữ tiêu đề, mô tả và status chip của disclosure quản trị.
- Giữ bố cục responsive hiện tại nhưng tránh text 8.x px ở phần quan trọng.

### 3. Attention-aware disclosure
- Nếu runtime ở Managed Mode hoặc Device Gate ở pending/blocked/offline/checking, disclosure quản trị được đánh dấu cần chú ý.
- Disclosure tự mở tối đa một lần trong phiên render runtime để người dùng thấy vấn đề.
- Ở Standalone Mode không có attention state và vẫn giữ hierarchy gọn.

## Không thay đổi
- Không đổi quotation/customer/product data.
- Không đổi backup schema.
- Không đổi import/export.
- Không đổi A4/PDF.
- Không bật Managed Mode mặc định.

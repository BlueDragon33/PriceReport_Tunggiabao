# V6.18 — PDF Print Isolation

## Lỗi thực tế

Khi người dùng bấm **Xuất PDF**, bản in có thể chứa cả thanh Studio phía trên, gồm tên báo giá, tìm kiếm, Lưu nháp, Xem trước và Xuất PDF. Nguyên nhân là print CSS cũ chỉ ẩn một số thành phần như nav/editor/design/preview-tools nhưng không cô lập toàn bộ application shell.

## Cách sửa

### Hard print isolation

V6.18 dùng stylesheet riêng `src/print-v618.css`, được nạp cuối cùng với `media="print"` để không làm tăng nợ kỹ thuật của report/UI CSS.

Trong print media, chỉ cây sau được giữ trong formatting tree:

```
.shell
└── .preview
    └── .paper-wrap
        └── .paper
```

Các sibling khác bị `display:none!important`.

### A4 contract

- `@page: A4 portrait`
- page margin: 0
- paper width: 210 mm
- minimum height: 297 mm
- `box-sizing:border-box`
- reset transform / translate / scale / zoom của preview màn hình

### Print controller

Mọi nút Xuất PDF gọi cùng `printQuoteDocument()`.

Controller:
- bật trạng thái `print-export-active`;
- gọi print dialog;
- đồng bộ với `beforeprint`;
- dọn trạng thái ở `afterprint`.

## Regression gates

1. `scripts/print-layout.test.mjs`
   - kiểm tra hard isolation selectors;
   - A4 geometry;
   - print controller;
   - multi-button binding.

2. Chromium browser gate
   - `emulateMedia({ media: 'print' })`;
   - xác nhận topbar/nav/editor/inspector/tools đều `display:none`;
   - xác nhận shell/preview/paper-wrap/paper đều rộng đúng A4;
   - paper bắt đầu tại x = 0.
